# 极速广告拦截器 Pro v3.0.0

Chrome 浏览器广告拦截插件，智能拦截各种网页广告，还你纯净浏览体验。

## v3.0 新功能

- 🎯 **Pro 版界面**：紫色渐变设计，更美观
- 🚀 **拦截规则升级**：从 10 种增加到 20+ 种广告选择器
- 📺 **新增视频广告拦截**：自动跳过视频片头广告
- 🎯 **智能关闭按钮识别**：向上查找 3 层父元素判断是否为广告
- 📊 **功能列表展示**：弹窗里显示所有支持的拦截类型

## 支持拦截的广告类型

| 类型 | 说明 |
|------|------|
| 弹窗广告 | 自动弹出的 modal/popup 窗口 |
| 悬浮广告 | 固定在角落的浮动广告 |
| 横幅广告 | 顶部/底部/banner 横幅 |
| iframe 广告 | iframe 嵌入的第三方广告 |
| 视频广告 | 视频片头/暂停广告 |
| 插入式广告 | 信息流中插入的推广内容 |

## 安装方法

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择 `extension` 文件夹

## 使用

安装后自动生效，浏览网页时自动拦截广告。
点击插件图标可以查看拦截数量和功能列表。

## 项目结构

```
extension/
├── manifest.json    # 插件配置（MV3）
├── content.js       # 广告拦截核心脚本
└── popup.html       # Pro 版弹窗界面
```
