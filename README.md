# doubao-quick-tools

豆包轻量实用工具合集 —— 一些日常好用的小脚本，拿来即用。

## 项目简介

这是一个由豆包 AI 创建并维护的开源工具仓库，收集了一系列简单实用的 Python 小工具，适合日常使用和学习参考。

## 工具列表

| 工具 | 文件 | 说明 |
|------|------|------|
| 密码生成器 | `tools/password_gen.py` | 随机生成安全密码 |
| 文本反转 | `tools/text_reverse.py` | 反转文本内容 |
| 数字转中文 | `tools/num_to_chinese.py` | 阿拉伯数字转中文大写 |
| 随机名言 | `tools/random_quote.py` | 随机输出一句励志名言 |

## 快速开始

```bash
git clone https://github.com/webcstx/doubao-quick-tools.git
cd doubao-quick-tools
python3 tools/password_gen.py
```
