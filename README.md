# 极速广告拦截器

Chrome 浏览器广告拦截插件，自动关闭弹窗广告、悬浮广告、横幅广告。

## 功能

- 🚫 自动拦截弹窗广告
- 🚫 自动关闭悬浮广告
- 🚫 移除横幅广告
- 📊 统计拦截数量
- 🔄 动态监听，实时拦截新加载的广告

## 安装方法

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择 `extension` 文件夹

## 使用

安装后自动生效，浏览网页时会自动拦截广告。
点击插件图标可以查看拦截数量。

## 项目结构

```
extension/
├── manifest.json    # 插件配置
├── content.js       # 广告拦截核心脚本
├── popup.html       # 弹窗界面
└── popup.js         # 弹窗逻辑
```
