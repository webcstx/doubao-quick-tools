# GKD 开屏广告跳过

GKD 订阅规则，自动跳过 App 开屏广告。

## 订阅地址

```
https://github.com/webcstx/doubao-quick-tools/releases/download/v3.0.1/gkd-subscription.json5
```

## 功能

- 🚀 自动跳过开屏广告
- 🎯 智能识别「跳过」按钮
- 🚫 不误点正常按钮（搜索、下一步等）
- 🌏 支持简体/繁体「跳过」

## 支持的广告类型

- 穿山甲开屏广告（tt_splash_skip_btn）
- 广点通开屏广告
- 通用开屏跳过按钮

## 使用方法

1. 打开 GKD App
2. 进入「订阅」页面
3. 添加订阅，粘贴上面的链接
4. 开启开关
5. 打开 App 自动跳过开屏广告
